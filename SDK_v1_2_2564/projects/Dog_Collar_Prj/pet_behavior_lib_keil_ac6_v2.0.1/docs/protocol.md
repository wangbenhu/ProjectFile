# 输入输出协议

## 输入

`pet_ai_push_sample` 每次接收一条 `pet_ai_sample_t`。

| 字段 | 类型 | 含义 |
|---|---|---|
| `t_ms` | `uint32_t` | 设备启动后的单调毫秒时间戳 |
| `ax, ay, az` | `int32_t` | 三轴加速度计原始整数 |
| `gx, gy, gz` | `int32_t` | 三轴陀螺仪原始整数 |

输入频率固定为 50Hz，六轴有效范围为 `-32768..32767`。量程、轴顺序、轴方向和佩戴位置必须与训练配置一致，不要在调用前换算成物理单位。相邻时间戳必须递增且间隔不超过 100ms；断流后调用 `pet_ai_reset`。

## 输出

仅当 `pet_ai_push_sample` 返回 `PET_AI_HAS_RESULT` 时，`pet_ai_result_t` 有效。首次结果在连续接收 250 条样本后产生，之后每 50 条样本最多产生一次结果。

| `class_id` | 状态 |
|---:|---|
| 1 | `static`，静态未佩戴 |
| 2 | `lying` |
| 3 | `running` |
| 4 | `sitting` |
| 5 | `sniffing` |
| 6 | `walking` |
| 9 | `other`，低置信度或不能可靠归入五种佩戴行为 |

编号 0、7、8 为后续迭代预留，当前版本永不输出。接口不输出字符串和置信度；置信度阈值在库内固定。

| 返回码 | 含义 |
|---:|---|
| `0` | 样本已接收，本次无结果 |
| `1` | 样本已接收，并产生结果 |
| `-1` | 空指针 |
| `-2` | 状态区未初始化 |
| `-3` | 时间戳错误或数据中断 |
| `-4` | 六轴值超出有效范围 |
