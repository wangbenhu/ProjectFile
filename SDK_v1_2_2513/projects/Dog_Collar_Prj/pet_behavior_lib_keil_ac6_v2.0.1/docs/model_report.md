# 模型说明

## 结构

- 5 秒未佩戴静止前置门。
- 5 秒历史大类门，区分运动、静态姿态和嗅闻。
- 3 秒子树，分别区分 walking/running 与 sitting/lying。
- 叶节点置信度低于 Q15 阈值 25485 时输出 `other=9`。
- 输入 50Hz，预热 5 秒，输出步长 1 秒。

## 校准结果

未佩戴静止门使用 196.022 秒连续静止数据，形成 168 个互不跨块的 5 秒窗口。15 次分组验证中，静止召回率 100%，佩戴数据误报率 0%，lying 误报率 0%。

低置信度门使用 50 个自采训练视频进行 5 组种子、每组 3 折的按视频交叉验证。组外已知行为覆盖率 94.62%，已接收窗口准确率 88.97%，running 覆盖率 90.65%。

冻结测试集共 258 个窗口：222 个输出已知行为，36 个输出 other；已知行为覆盖率 86.05%，已接收窗口准确率 78.83%。running 共 11 个窗口，接收 8 个，其中 6 个正确，样本量较小。

## 边界

当前未佩戴模型只覆盖绝对静止状态。放包走动、地面振动和充电状态需补充数据。传感器 ODR、滤波、位置、量程或轴映射改变后必须重新验证。
